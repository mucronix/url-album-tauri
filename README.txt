URL Album 2.3.1-beta
====================
Портативный менеджер закладок. Не требует установки, не пишет в реестр.
Windows 10/11.

Обозначения:  + новое   ! исправлено   - удалено

ЧТО НОВОГО В 2.3.1-beta
-----------------------
+ Повторный запуск показывает уже открытое окно вместо второй копии.
  Раньше щелчок по ярлыку при работающей программе открывал ещё одну,
  с той же базой. Теперь окно просто выходит на передний план, даже
  если было свёрнуто в трей.
+ Работает на чистой Windows без дополнительных установок. Раньше на
  системе без Microsoft Visual C++ Redistributable программа не
  запускалась вовсе — окно с надписью «не обнаружена VCRUNTIME140.dll».
! «Открывать через…» теперь действует при любом способе открытия
  ссылки. Раньше настройку учитывали не все пути: карточка, строка
  с адресом внизу окна, результат поиска и пункт «Открыть» в меню по
  правой кнопке открывали ссылку системным браузером, и два способа
  открыть одну и ту же ссылку давали разные браузеры.
! Список браузеров и панель инструментов больше не теряются, если файл
  настроек испорчен. Программа применяет значения по умолчанию,
  сохраняет прежний файл рядом с собой (browsers.json.bad) и сообщает
  об этом одним окном.
! Программа больше не молчит, когда ссылка или картинка не открылась.
  Теперь она называет причину: браузер не найден (например, удалён или
  лежал на съёмном диске), файл отсутствует.
- Убран пункт «Открыть в переносном браузере»: он никогда не работал
  и всегда открывал окно «Открыть с помощью». Тот же выбор доступен
  в подменю «Открыть с помощью».

ЧТО НОВОГО В 2.3.0-beta
-----------------------
+ Сворачивание в трей: кнопка в правом углу строки меню и пункт
  «Файл → Свернуть в трей». Программа продолжает работать — значок
  остаётся в трее, «Добавить из буфера» и горячая клавиша доступны.
  Кнопку можно вынести на панель инструментов; в компактном режиме
  (строка меню скрыта) это единственный способ ею пользоваться.
+ Значок в трее: щелчок левой кнопкой показывает или прячет окно
  программы, меню открывается правой. Раньше меню появлялось по любой
  кнопке, и показать окно можно было только через него.
+ Поддержка прокси: вкладка «Прокси» в настройках теперь рабочая —
  в 2.1-beta она была убрана как нерабочая. Прокси используется при
  загрузке значков сайтов, проверке ссылок и создании скриншотов,
  в том числе с логином и паролем. Кнопка «Проверить» сразу сообщает,
  работает ли подключение.
+ Журнал для диагностики: «Настройки → Общие → Вести журнал». Выключен
  по умолчанию, размер ограничен: при 2 МБ прежние записи уходят
  в url-album.log.old. Если что-то не работает — включите, повторите
  действие и пришлите файл url-album.log: так проще найти причину.
! Надёжное сохранение при выходе: раньше последние изменения могли не
  попасть в файл базы, если скопировать album.db сразу после закрытия
  программы.
! Резервные копии теперь всегда содержат самые свежие изменения.
! Настройки больше не сбрасываются, если файл settings.json был открыт
  и сохранён в Блокноте.
! Убрано лишнее меню браузера, всплывавшее при правом клике на пустых
  местах окна.
! Исправлено «Очистить базу»: при ошибке закладки больше не удаляются,
  а сообщение об отказе теперь соответствует действительности.

УСТАНОВКА ПРОГРАММЫ
-------------------
1. Распакуйте архив в любую папку.
2. Запустите URL-Album.exe.

Папку extension НЕ удаляйте — она нужна для браузерного расширения.

УСТАНОВКА РАСШИРЕНИЯ (Chrome / Edge)
------------------------------------
1. Откройте страницу расширений:
   - Edge:   edge://extensions
   - Chrome: chrome://extensions
2. Включите "Режим разработчика".
3. Нажмите "Загрузить распакованное" и выберите папку extension
   из этого архива.
4. Иконка URL Album появится на панели браузера (её нужно будет закрепить).

ВАЖНО: программа URL Album должна быть запущена — расширение
связывается с ней. Если программа закрыта, расширение покажет
"URL Album не запущен".

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Запустите URL Album.
2. Откройте нужную страницу в браузере.
3. Нажмите иконку расширения.
4. Выберите папку, в которую сохранить ссылку (по умолчанию "Новые ссылки").
5. Нажмите "Добавить в URL Album".
6. Ссылка со скриншотом появится в выбранной папке.

ИСТОРИЯ ВЕРСИЙ
--------------
2.3.1-beta
  + Повторный запуск показывает уже открытое окно вместо второй копии. Раньше щелчок по ярлыку при работающей программе открывал ещё одну, работающую с той же базой. Теперь вторая копия молча завершается, а окно уже запущенной программы выходит на передний план — в том числе когда она свёрнута в трей. Ссылка, открытая через urlalbum://, попадает в уже запущенную программу, а не теряется; заодно исправлены испорченные русские буквы в названии такой ссылки.
  + Работает на чистой Windows без дополнительных установок. Раньше на системе, где не установлен Microsoft Visual C++ Redistributable, программа не запускалась вовсе — Windows показывала окно «Не удаётся продолжить выполнение кода, поскольку не обнаружена VCRUNTIME140.dll». Теперь всё необходимое встроено в сам файл программы, портативность больше ничем не ограничена. Программа выросла на 143 КБ.
  ! «Открывать через…» теперь действует при любом способе открытия ссылки. Раньше настройку учитывали двойной щелчок в дереве и в списке, Enter и пункт «Открыть» в меню «Ссылки», а карточка (кнопка «Открыть в браузере», щелчок по адресу, двойной щелчок по картинке), строка с адресом внизу окна, результат поиска и пункт «Открыть» в меню по правой кнопке — нет: они открывали ссылку системным браузером. Из-за этого два способа открыть одну и ту же ссылку давали разные браузеры.
  ! Список браузеров и панель инструментов больше не теряются, если файл настроек испорчен — например, открыт и сохранён в Блокноте с другой кодировкой или обрезан при сбое. Раньше в таком случае молча применялись значения по умолчанию, и первое же сохранение затирало файл: пропадали вручную добавленные пути к переносным браузерам и расстановка кнопок. Теперь прежний файл сохраняется рядом с программой (browsers.json.bad, toolbar.json.bad), и программа сообщает об этом одним окном, даже если испорчено несколько файлов сразу. В такой копии settings.json.bad код доступа для расширения браузера заменяется звёздочками — файл можно приложить к письму или сообщению на форуме.
  ! Программа больше не молчит, когда ссылка или картинка не открылась. Раньше щелчок по ссылке мог не дать вообще ничего: ни окна браузера, ни сообщения. Теперь программа называет причину — браузер не найден (удалён или лежал на съёмном диске), файл отсутствует, для ссылок такого вида не назначена программа.
  - Убран пункт «Открыть в переносном браузере» из меню «Ссылки»: он никогда не работал и всегда открывал окно «Открыть с помощью». Тот же выбор доступен в подменю «Открыть с помощью» по правой кнопке, где перечислены все браузеры, включая переносные.

2.3.0-beta
  + Сворачивание в трей: кнопка в правом углу строки меню и пункт «Файл → Свернуть в трей». Программа не закрывается, а продолжает работать — значок остаётся в трее, «Добавить из буфера» и горячая клавиша по-прежнему доступны. Кнопку можно вынести на панель инструментов через настройку панели; в компактном режиме, когда строка меню скрыта, это единственный способ ею пользоваться.
  + Значок в трее: щелчок левой кнопкой показывает или прячет окно программы, меню открывается правой кнопкой. Раньше меню появлялось по любой кнопке, и показать окно можно было только выбрав в нём пункт «Показать URL-Album».
  + Поддержка прокси: вкладка «Прокси» в настройках теперь рабочая — в 2.1-beta она была убрана как нерабочая, теперь появилась заново и работает. Поля: адрес, порт, логин, пароль. Кнопка «Проверить» сразу сообщает, работает ли подключение, не дожидаясь сохранения настроек.
  + Журнал для диагностики: «Настройки → Общие → Вести журнал», выключен по умолчанию. Размер ограничен: когда файл достигает 2 МБ, прежние записи уходят в url-album.log.old, так что журнал не растёт бесконечно. Если что-то не работает — включите запись, повторите действие и пришлите файл url-album.log, который появится рядом с программой: по нему проще найти причину. Рядом кнопка «Открыть журнал».
  ! Надёжное сохранение при выходе: раньше последние изменения могли не попасть в файл базы, если скопировать album.db сразу после закрытия программы. Теперь при выходе данные всегда дописываются в базу.
  ! Резервные копии теперь всегда содержат самые свежие изменения — раньше в копию могли не попасть последние правки.
  ! Настройки больше не сбрасываются, если файл settings.json был открыт и сохранён в Блокноте.
  ! Убрано лишнее меню браузера («Назад», «Обновить», «Сохранить как»), всплывавшее при правом клике на пустых местах окна.
  ! Исправлено «Очистить базу»: при ошибке закладки больше не удаляются, а сообщение об отказе теперь соответствует действительности.
