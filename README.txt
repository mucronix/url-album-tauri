URL Album 2.2.4-beta
====================
Портативный менеджер закладок. Не требует установки, не пишет в реестр.
Windows 10/11.

ЧТО НОВОГО В 2.2.4-beta
-----------------------
+ Корзина: удалённые папки и ссылки попадают в Корзину, а не стираются сразу.
  Их можно восстановить (папки — со всем содержимым) или удалить окончательно.
  Внизу дерева появился раздел «Корзина».
+ Компактный режим: кнопка в панели инструментов скрывает главное меню,
  освобождая место. Повторное нажатие возвращает меню.
+ «Переместить в...»: новый пункт контекстного меню — переместить ссылку
  или папку в другую через диалог выбора папки.
! Исправлены дубли превью-картинок: при обновлении/удалении картинки
  старые файлы больше не накапливаются на диске.

УСТАНОВКА ПРОГРАММЫ
-------------------
1. Распакуйте архив в любую папку.
2. Запустите URL-Album.exe.

Папку extension НЕ удаляйте — она нужна для браузерного расширения.

УСТАНОВКА РАСШИРЕНИЯ (Chrome / Edge)
------------------------------------
1. Откройте страницу расширений:
   - Edge:   edge://extensions
   - Chrome: chrome://extensions
2. Включите "Режим разработчика".
3. Нажмите "Загрузить распакованное" и выберите папку extension
   из этого архива.
4. Иконка URL Album появится на панели браузера (её нужно будет закрепить).

ВАЖНО: программа URL Album должна быть запущена — расширение
связывается с ней. Если программа закрыта, расширение покажет
"URL Album не запущен".

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Запустите URL Album.
2. Откройте нужную страницу в браузере.
3. Нажмите иконку расширения.
4. Выберите папку, в которую сохранить ссылку (по умолчанию "Новые ссылки").
5. Нажмите "Добавить в URL Album".
6. Ссылка со скриншотом появится в выбранной папке.

ИСТОРИЯ ВЕРСИЙ
--------------
2.2.4-beta
  + Корзина: удалённые папки и ссылки попадают в Корзину, а не стираются
    сразу. Их можно восстановить (папки — со всем содержимым) или удалить
    окончательно. Внизу дерева появился раздел «Корзина».
  + Компактный режим: кнопка в панели инструментов скрывает главное меню,
    освобождая место. Повторное нажатие возвращает меню.
  + «Переместить в...»: новый пункт контекстного меню — переместить ссылку
    или папку в другую через диалог выбора папки.
  ! Исправлены дубли превью-картинок: при обновлении/удалении картинки
    старые файлы больше не накапливаются на диске.

2.2.3-beta
  + Имя текущей базы показывается в строке над деревом папок.
  + Перетаскивание для изменения порядка ссылок и папок (раньше только
    стрелками) — и в списке справа, и для папок в дереве слева.
  + Перемещение папок стрелками вверх/вниз.
  + Разные значки на кнопках "Новая папка" и "Новая подпапка".
  ! Ручная сортировка стрелками теперь сохраняется между запусками.
  ! Исправлено: папка "Новые ссылки" (и любая единственная корневая
    папка) больше не пропадает из дерева.
  ! Импорт ua.dat на стартовом экране — теперь через диалог выбора файла,
    а не вводом пути вручную.
  ! Скриншоты страниц больше не теряются при переносе папки с программой.

2.2.2-beta
  + Автопрокрутка дерева при перетаскивании ссылки или папки к верхнему
    или нижнему краю — список сам прокручивается до папок вне видимости.
  ! Зона перетаскивания в корень больше не перекрывает верхнюю папку.

2.2.1-beta
  + Выбор папки при сохранении ссылки из браузера.
  + Папка по умолчанию переименована во "Новые ссылки".
  ! Исправлено сворачивание дерева папок после обновления фавиконок.

2.2.0-beta
  + Браузерное расширение для Chrome и Edge: сохранение ссылки
    с открытой вкладки одним кликом, автоматический скриншот.
  + Автоматическая настройка связи программы и расширения.

2.1.1-beta
  + Рисунки обновляются в интерфейсе сразу после завершения пакета,
    без перезапуска программы.
  ! Исправлена путаница скриншотов при пакетном обновлении рисунков.
  ! Убран пункт меню "Файл -> Выход" (закрытие через крестик в заголовке).

2.1-beta
  + Импорт из другой базы URL Album (с отсевом дубликатов и воссозданием
    дерева папок).
  + Настройка размера шрифта интерфейса (8-18 pt, Настройки -> Общие).
  + Drag & Drop ссылок и папок в корень дерева.
  ! Перестроено меню "Файл", убраны дублирующие пункты.
  ! Убрана нерабочая вкладка "Прокси".

2.0-beta
  + Первый публичный релиз. Дерево папок + список ссылок, drag & drop,
    favicons, скриншоты страниц, поиск (Ctrl+F), импорт из браузеров
    (Chrome, Firefox, Edge, Opera, Brave), несколько баз данных.
