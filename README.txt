URL Album 2.3.0-beta
====================
Портативный менеджер закладок. Не требует установки, не пишет в реестр.
Windows 10/11.

Обозначения:  + новое   ! исправлено   - удалено

ЧТО НОВОГО В 2.3.0-beta
-----------------------
+ Сворачивание в трей: кнопка в правом углу строки меню и пункт
  «Файл → Свернуть в трей». Программа продолжает работать — значок
  остаётся в трее, «Добавить из буфера» и горячая клавиша доступны.
  Кнопку можно вынести на панель инструментов; в компактном режиме
  (строка меню скрыта) это единственный способ ею пользоваться.
+ Поддержка прокси: вкладка «Прокси» в настройках теперь рабочая —
  в 2.1-beta она была убрана как нерабочая. Прокси используется при
  загрузке значков сайтов, проверке ссылок и создании скриншотов,
  в том числе с логином и паролем. Кнопка «Проверить» сразу сообщает,
  работает ли подключение.
+ Журнал для диагностики: «Настройки → Общие → Вести журнал». Выключен
  по умолчанию, размер ограничен: при 2 МБ прежние записи уходят
  в url-album.log.old. Если что-то не работает — включите, повторите
  действие и пришлите файл url-album.log: так проще найти причину.
! Надёжное сохранение при выходе: раньше последние изменения могли не
  попасть в файл базы, если скопировать album.db сразу после закрытия
  программы.
! Резервные копии теперь всегда содержат самые свежие изменения.
! Настройки больше не сбрасываются, если файл settings.json был открыт
  и сохранён в Блокноте.
! Убрано лишнее меню браузера, всплывавшее при правом клике на пустых
  местах окна.
! Исправлено «Очистить базу»: при ошибке закладки больше не удаляются,
  а сообщение об отказе теперь соответствует действительности.

УСТАНОВКА ПРОГРАММЫ
-------------------
1. Распакуйте архив в любую папку.
2. Запустите URL-Album.exe.

Папку extension НЕ удаляйте — она нужна для браузерного расширения.

УСТАНОВКА РАСШИРЕНИЯ (Chrome / Edge)
------------------------------------
1. Откройте страницу расширений:
   - Edge:   edge://extensions
   - Chrome: chrome://extensions
2. Включите "Режим разработчика".
3. Нажмите "Загрузить распакованное" и выберите папку extension
   из этого архива.
4. Иконка URL Album появится на панели браузера (её нужно будет закрепить).

ВАЖНО: программа URL Album должна быть запущена — расширение
связывается с ней. Если программа закрыта, расширение покажет
"URL Album не запущен".

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Запустите URL Album.
2. Откройте нужную страницу в браузере.
3. Нажмите иконку расширения.
4. Выберите папку, в которую сохранить ссылку (по умолчанию "Новые ссылки").
5. Нажмите "Добавить в URL Album".
6. Ссылка со скриншотом появится в выбранной папке.

ИСТОРИЯ ВЕРСИЙ
--------------
2.3.0-beta
  + Сворачивание в трей: кнопка в правом углу строки меню и пункт «Файл → Свернуть в трей». Программа не закрывается, а продолжает работать — значок остаётся в трее, «Добавить из буфера» и горячая клавиша по-прежнему доступны. Кнопку можно вынести на панель инструментов через настройку панели; в компактном режиме, когда строка меню скрыта, это единственный способ ею пользоваться.
  + Поддержка прокси: вкладка «Прокси» в настройках теперь рабочая — в 2.1-beta она была убрана как нерабочая, теперь появилась заново и работает. Поля: адрес, порт, логин, пароль. Прокси используется при загрузке значков сайтов, проверке ссылок и создании скриншотов, в том числе если он требует логин и пароль. Кнопка «Проверить» сразу сообщает, работает ли подключение, не дожидаясь сохранения настроек.
  + Журнал для диагностики: «Настройки → Общие → Вести журнал», выключен по умолчанию. Размер ограничен: когда файл достигает 2 МБ, прежние записи уходят в url-album.log.old, так что журнал не растёт бесконечно. Если что-то не работает — включите запись, повторите действие и пришлите файл url-album.log, который появится рядом с программой: по нему проще найти причину. Рядом кнопка «Открыть журнал».
  ! Надёжное сохранение при выходе: раньше последние изменения могли не попасть в файл базы, если скопировать album.db сразу после закрытия программы. Теперь при выходе данные всегда дописываются в базу.
  ! Резервные копии теперь всегда содержат самые свежие изменения — раньше в копию могли не попасть последние правки.
  ! Настройки больше не сбрасываются, если файл settings.json был открыт и сохранён в Блокноте.
  ! Убрано лишнее меню браузера («Назад», «Обновить», «Сохранить как»), всплывавшее при правом клике на пустых местах окна.
  ! Исправлено «Очистить базу»: при ошибке закладки больше не удаляются, а сообщение об отказе теперь соответствует действительности.

2.2.5-beta

  + Системный трей: пункты «Показать», «Добавить из буфера», «Выход».
  + Горячая клавиша F8 (и настраиваемая своя) для быстрого добавления ссылки из буфера обмена.
  + «Открывать через...»: выбор браузера для папки, подпапки наследуют выбор.
  + Перетаскивание всех окон за заголовок; окна закрываются только крестиком, Esc или «Отмена».
  + Поддержка крупного шрифта: поля, кнопки и метки в диалогах подстраиваются под размер шрифта.
  + Импорт закладок из всех профилей браузеров Chrome, Edge, Brave, Vivaldi (раньше — только основной профиль).
  + Окна-уведомления с результатом при резервном копировании, экспорте и импорте.
  ! Надёжное массовое обновление скриншотов: на быстрых компьютерах больше не теряется часть картинок. Убраны дубликаты, картинка появляется сразу без повторного клика.
  ! Ускорена загрузка значков сайтов (favicon) и скриншотов.
  ! Служебные адреса (edge://, chrome://, about:, mailto:) при проверке помечаются как «не проверяется», а не «ошибка».
  ! Исправлено резервное копирование вместе с картинками.
  ! Другие мелкие исправления и улучшения.
