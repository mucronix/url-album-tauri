URL Album 2.3.5-beta
====================
Портативный менеджер закладок. Не требует установки, не пишет в реестр.
Windows 10/11; для Windows 7 SP1 (64-бит) — отдельная сборка.

Обозначения:  + новое   ! исправлено   - удалено

ЧТО НОВОГО В 2.3.5-beta
-----------------------
+ Английский и украинский языки. При первом запуске программа говорит
  на языке Windows, а если для него нет перевода — по-английски.
  Сменить язык: «Настройки → Общие → Язык», действует после
  перезапуска. Свой перевод можно положить в папку lang рядом
  с программой — см. «ЯЗЫК ПРОГРАММЫ» ниже.
+ Расширение браузера — на языке браузера: русском, английском или
  украинском, для остальных языков — на английском.
+ F8 можно отключить: галочка «F8 — добавить из буфера» в «Настройки →
  Общие». Клавиша освобождается для других программ, дополнительная
  комбинация работает как прежде. По просьбе maK.
+ Окно программы запоминает размер, положение и «развёрнуто». При
  первом запуске окно меньше прежнего и целиком помещается на экран,
  в том числе на ноутбуке с крупным масштабом; если монитор, на
  котором оно было, отключён, окно открывается на основном. По просьбе
  greeple.
+ «Выход» в меню «Файл». Выход из меню и из трея сохраняет заметку,
  которую вы в этот момент правите. «Свернуть в трей» — кнопкой у
  правого края строки меню и щелчком по значку в трее; из меню «Файл»
  и из панели инструментов по умолчанию этот пункт убран (вынести
  кнопку на панель по-прежнему можно). По просьбе greeple.
! Переименование папки: щелчок, двойной щелчок и выделение мышью
  внутри поля больше не закрывают правку.
! Отмена окна выбора файла при экспорте из меню «Перенос» больше
  не показывает «Ошибка экспорта».
! Импорт TXT: ссылка с названием вроде «Заметка: план» больше не
  пропадает, превратившись в заметку соседней ссылки; заметка,
  начинающаяся с пустой строки, больше не теряется. Экспорт в TXT
  подписывает заметки на языке программы, импорт узнаёт подпись
  на любом из трёх языков.
! Папка «Новые ссылки» остаётся служебной после переименования:
  расширение предлагает её по умолчанию, и вторая «Новые ссылки»
  рядом больше не заводится.
! Сообщения при переносе и импорте из другой базы показываются окном
  программы, а не системным окном.
! Выпадающие меню не уходят за край узкого окна.

Обновление расширения: замените файлы в папке, из которой расширение
было загружено, файлами из папки extension этого архива, затем
в chrome://extensions (edge://extensions) нажмите значок перезагрузки
у URL Album.

  пока над ними мышь; длинный текст виден целиком во всплывающей

  всегда, прокручивается только середина. Окно «Настройки» больше не
  меняет высоту при переключении вкладок.
! Итог загрузки значков сайтов честно считает ненайденные значки
  неудачами, а не удачами.
! В новой или очищенной базе сразу есть папка «Новые ссылки». Раньше
  в базе без папок «Новая ссылка», F8 и «Добавить из буфера» молча
  не сохраняли ссылку. Пустой адрес теперь подсказывается.

ЧТО НОВОГО В 2.3.3-beta
-----------------------
+ Большие базы работают быстро. На базе в 91 000 ссылок и 3 800 папок
  создание папки занимало около 7 секунд, теперь — доли секунды; так же
  быстро добавление ссылки, перетаскивание и «Переместить в…». База
  открывается быстрее, окно «Переместить в…» больше не думает 17 секунд.
+ Заметка правится прямо на месте: щёлкните по ней под списком или в
  карточке. Высоту заметки можно менять, потянув за её верхний край.
+ Дата добавления ссылки. Показывается внизу окна и в «Свойствах».
  При импорте из браузеров и HTML сохраняется исходная дата закладки,
  при экспорте в HTML — записывается в файл.
+ Строка состояния, как в старом URL-Album: внизу окна дата добавления
  выделенной ссылки и дата её рисунка. Текст внизу стал крупнее и чётче.
+ Переход набором букв, как в Проводнике: наберите начало названия в
  дереве или в списке — выделится первый подходящий элемент. Enter по
  выделенной папке в списке открывает её.
+ Правая кнопка в полях ввода открывает меню «Отменить / Вырезать /
  Копировать / Вставить / Удалить / Выделить всё».
+ Меню «Справка» и окно «О программе». Программа выпускается под
  лицензией GNU GPL 3.0 или более поздней — текст в файле LICENSE.
! «Добавить из буфера» (трей, F8) больше не спрашивает разрешения на
  доступ к буферу обмена.
! Расширение браузера не добавляет повторно уже сохранённый адрес, если
  включено «Запретить повторяющиеся ссылки», и сообщает, в какой папке
  он уже есть. Обновите расширение: см. ниже.
! Переименование папки сразу видно в правой панели и в пути сверху.
! «Переместить в…» раскрывает путь к папке назначения.
- Программа больше не пишет в реестр. Раньше при каждом запуске она
  регистрировала ссылки вида urlalbum://. Ключ HKCU\Software\Classes\urlalbum,
  оставшийся от прошлых версий, можно удалить вручную: программа его больше
  не создаёт и при запуске не использует.

Обновление расширения: замените файлы в папке, из которой расширение
было загружено, файлами из папки extension этого архива (или загрузите
расширение заново из новой папки), затем в chrome://extensions
(edge://extensions) нажмите значок перезагрузки у URL Album. Со старым
расширением при включённой «Запретить повторяющиеся ссылки» повторный
адрес покажется как «Добавлено ✓», хотя добавлен не будет.

При первом открытии базы новой версией в ней создаётся служебный индекс
(на базе в 91 000 ссылок — около 0,2 секунды, файл немного растёт).
Прежние версии с такой базой работают как раньше.

УСТАНОВКА ПРОГРАММЫ
-------------------
1. Распакуйте архив в любую папку.
2. Запустите URL-Album.exe.

Папку extension НЕ удаляйте — она нужна для браузерного расширения.

Windows может показать окно «Система Windows защитила ваш компьютер».
Это фильтр SmartScreen: программа не подписана платным сертификатом
разработчика, поэтому система её пока не знает. Нажмите «Подробнее»,
затем «Выполнить в любом случае». Исходный код открыт:
https://github.com/mucronix/url-album-tauri

Обычно WebView2 уже есть в Windows 10/11. Если при запуске программа
сообщает «Could not find the WebView2 Runtime» — установите Microsoft
Edge WebView2 Runtime (Evergreen Bootstrapper) с сайта Microsoft:
https://developer.microsoft.com/microsoft-edge/webview2/
Это бесплатно и около 2 МБ.

Для Windows 7 — см. ПРОЧТИ-WINDOWS7.txt в архиве для Windows 7.

УСТАНОВКА РАСШИРЕНИЯ (Chrome / Edge)
------------------------------------
1. Откройте страницу расширений:
   - Edge:   edge://extensions
   - Chrome: chrome://extensions
2. Включите "Режим разработчика".
3. Нажмите "Загрузить распакованное" и выберите папку extension
   из этого архива.
4. Иконка URL Album появится на панели браузера (её нужно будет закрепить).

ВАЖНО: программа URL Album должна быть запущена — расширение
связывается с ней. Если программа закрыта, расширение покажет
"URL Album не запущен".

ОБНОВЛЕНИЕ ПРОГРАММЫ
--------------------
1. Закройте программу.
2. Распакуйте новый архив в ту же папку, поверх старых файлов.
3. Запустите URL-Album.exe.

Ваши данные при этом не пострадают: архив содержит только программу,
README и папку extension. База закладок, скриншоты в папке Data
и настройки лежат отдельно и не перезаписываются.

Служебные файлы окна программы (профиль WebView2) лежат в папке
WebView2 рядом с программой. Прежние версии хранили их в папке
%LOCALAPPDATA%\com.urlalbum.app — она больше не нужна, её можно
удалить вручную. Если в папку программы нельзя записывать (например,
Program Files) или она на сетевом диске, профиль по-прежнему хранится
в %LOCALAPPDATA%\com.urlalbum.app.

Расширение браузера обновляется само вместе с папкой extension:
переустанавливать его не нужно. Если хотите применить обновление сразу,
откройте страницу расширений браузера и нажмите "Обновить" в верхней
части страницы.

Важно: не переносите и не переименовывайте папку с программой после
установки расширения - браузер запоминает путь к папке extension
и после переноса потеряет расширение. Если папку всё же пришлось
переместить, установите расширение заново из нового расположения.

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Запустите URL Album.
2. Откройте нужную страницу в браузере.
3. Нажмите иконку расширения.
4. Выберите папку, в которую сохранить ссылку (по умолчанию "Новые ссылки").
5. Нажмите "Добавить в URL Album".
6. Ссылка со скриншотом появится в выбранной папке.

ЯЗЫК ПРОГРАММЫ
--------------
Язык меняется в «Настройки → Общие → Язык» и включается после
перезапуска. Свой перевод: файл lang\<код>.json рядом с URL-Album.exe
(образец — src-tauri/lang/en.json на GitHub); строки, которых в нём
нет, останутся английскими.

2.3.5-beta
  + Английский и украинский языки интерфейса. Переведено всё, что видно в окне: меню, окна, настройки, сообщения, меню трея, окна выбора файла, названия папок, которые заводит сама программа. При первом запуске язык берётся из Windows; если перевода на него нет — английский. Выбор — «Настройки → Общие → Язык»: «Авто — язык системы» или любой из доступных; новый язык включается после перезапуска программы. Даты показываются в привычном для языка виде. Журнал по-прежнему пишется по-русски. Папка «Новые ссылки» в уже существующих базах не переименовывается; в новой базе на английском она называется «New links».
  + Свой перевод: файл lang\<код языка>.json рядом с программой (например, lang\de.json) появляется в списке языков под названием из файла; файл с тем же кодом, что у встроенного языка, подменяет его строки. Недостающие строки берутся из встроенного словаря того же языка, а если его нет — из английского. Испорченный файл не читается, программа сообщает об этом и работает на встроенном языке.
  + Расширение браузера — на языке браузера (не программы): русский, английский, украинский; для остальных языков — английский. Описание в списке расширений, подсказка у значка и все надписи в окне расширения переведены. Распакованное расширение нужно перезагрузить из новой папки extension.
  + Галочка «F8 — добавить из буфера» в «Настройки → Общие» (по просьбе maK). Снятая галочка освобождает F8 сразу, без перезапуска, — клавиша достаётся другим программам (например, Total Commander). Дополнительная горячая клавиша работает независимо от галочки.
  + Окно программы запоминает размер, положение и «развёрнуто» между запусками — в settings.json рядом с программой, как и остальные настройки (по просьбе greeple). При первом запуске окно 1000×650 вместо 1200×750 и не больше 90 % экрана: раньше на ноутбуке с масштабом 150 % оно не помещалось. Если сохранённое место оказалось за пределами экранов (отключили второй монитор, сменили разрешение), окно открывается по центру основного экрана.
  + «Выход» снова в меню «Файл» (по просьбе greeple; убран в 2.1.1-beta). Выход из меню и пункт «Выход» в трее сначала сохраняют заметку, которую вы правите, — раньше выход из трея мог её потерять. «Свернуть в трей» остался кнопкой у правого края строки меню и щелчком по значку в трее; из меню «Файл» и из панели инструментов по умолчанию он убран. Если вы выносили кнопку на панель, она останется; добавить её можно в настройке панели инструментов.
  ! Переименование папки: щелчок внутри поля (например, чтобы поставить курсор), двойной щелчок по слову и выделение мышью закрывали правку или начинали перетаскивание строки. Теперь правка закрывается только по Enter, Esc или щелчку вне поля.
  ! Отмена окна выбора файла при экспорте из меню «Перенос» показывала «Ошибка экспорта» и писала её в журнал. Теперь отмена — просто отмена, как и во всех остальных окнах выбора файла.
  ! Импорт TXT. Ссылка, название которой начинается с «Заметка:» (например, «Заметка: план»), при импорте пропадала — её строка читалась как заметка предыдущей ссылки. Заметка, первая строка которой пустая, терялась целиком. Теперь обе возвращаются при импорте. Экспорт в TXT подписывает заметки на языке программы («Note:», «Нотатка:»; на русском файл прежний), импорт узнаёт подпись на любом из встроенных языков — файл, выгруженный на одном языке, читается на другом. Файл с русской подписью читают и прежние версии, с «Note:» или «Нотатка:» — только 2.3.5 и новее.
  ! Папка «Новые ссылки» узнаётся по служебной отметке, а не по названию. Раньше после переименования, например в «Входящие», окно расширения предлагало по умолчанию первую папку списка, а ссылка, отправленная без выбора папки, попадала в заново заведённую вторую «Новые ссылки». Теперь переименованная остаётся служебной; служебной перестаёт быть папка, перенесённая внутрь другой или удалённая в корзину. В существующей базе отметку получает корневая папка «Новые ссылки» — при первом открытии этой версией. Расширение выбирает её по отметке; старое расширение с новой программой — по названию, как раньше.
  ! Сообщения при переносе (экспорт и импорт) и при импорте из другой базы показывались системным окном — теперь окном программы.
  ! Выпадающие меню и подменю не уходят за край узкого окна.

2.3.4-beta
  + Выбор браузера для рисунка страницы. Раньше снимок делали только Edge или Chrome по жёстко заданным путям, а на машине без них — например, на Windows 7 с одной Opera — рисунков не было вовсе («Edge или Chrome не найден»), и выбор браузера в программе не учитывался. Теперь снимает браузер из «Открывать через…» корневой папки, иначе браузер по умолчанию из списка «Браузеры» (или браузер, назначенный в Windows); если он снимать не умеет или его файла нет на месте (например, переносной браузер уехал вместе с флешкой) — первый умеющий из списка «Браузеры», затем Edge, Chrome, Opera, Яндекс. Если выбранный браузер запустился, но снимка не получилось, программа сообщает об ошибке и другим браузером не переснимает. Снимают проверенные Edge, Chrome и Opera до версии 95 включительно; Brave, Vivaldi, Firefox и Opera новее 95 пока не умеют (запуск headless у них не делает снимок) — их программа пропускает. Когда снял не назначенный, а запасной браузер, внизу окна сказано, какой и почему; в журнале каждая строка снимка называет браузер.
  + Отдельная сборка для Windows 7 SP1 (64-бит). Обычная сборка на Windows 7 не запускается: её стандартная библиотека требует функций Windows 8 и новее. Для Windows 7 нужны обновления SHA-2 (KB4490628, KB4474419) и Microsoft Edge WebView2 версии 109 — последней для Windows 7; браузер по умолчанию программа на Windows 7 определяет и без «Программ по умолчанию».
  ! Несуществующий или недоступный адрес больше не даёт белый рисунок, засчитанный удачей. Перед запуском браузера программа проверяет, что имя сайта находится и сайт принимает соединение (до 5 секунд), и сообщает причину: «адрес не найден», «соединение отклонено», «нет ответа». Прежний рисунок ссылки при этом не стирается. При включённом прокси проверка не делается. Медленный сайт, который отвечает, но не успевает загрузиться за «Время ожидания», по-прежнему может дать пустой рисунок.
  ! Браузер, запущенный для снимка, больше не остаётся работать после съёмки. Раньше Opera, а иногда и другие браузеры, оставляли после себя процессы, которые жили до перезагрузки, и временные папки профиля в %TEMP%. Теперь программа снимает браузер вместе со всеми его процессами, удаляет временную папку, а папки, оставшиеся от прошлых запусков (старше часа), убирает при старте.
  ! Одну ссылку нельзя снимать дважды одновременно — например, «Обновить рисунок» во время пакетного обновления папки. Раньше два снимка мешали друг другу и могли стереть или подменить результат. Второй запуск отклоняется с сообщением «Рисунок этой ссылки уже снимается», в пакете такая ссылка считается пропущенной: итог «удалось N, не удалось M, пропущено K».
  ! Строка состояния: обычное сообщение висит от 5 до 12 секунд в зависимости от длины (раньше 3 секунды на любое), не гаснет, пока над строкой мышь, и затем держится ещё не меньше 2 секунд. Длинный текст справа, обрезанный многоточием, виден целиком во всплывающей подсказке — подсказка появляется только когда текст действительно обрезан. Шрифт строки состояния — как у остального интерфейса, текст жирнее. Ошибка отдельного снимка во время пакета больше не затирает ход пакета — она попадает в итог и журнал.
  ! Окна программы — «Настройки», «Браузеры», «Дубликаты ссылок» и остальные — помещаются в небольшое окно программы: раньше в невысоком окне у «Настроек» пропадали заголовок и кнопки «Сохранить» / «Отмена». Теперь окно не выше и не шире окна программы, заголовок и кнопки видны всегда, прокручивается только середина. Окно «Настройки» больше не меняет высоту при переключении вкладок.
  ! Итог пакетной загрузки значков сайтов считал ненайденный значок удачей: «удалось 3, не удалось 0», хотя для двух сайтов не нашлось ничего. Теперь — «удалось N, не удалось M», так же и в строке состояния.
  ! Пустая база. В базе без единой папки окно «Новая ссылка» — а с ним F8 и «Добавить из буфера» в трее — молча не сохраняло ссылку: ни кнопка «Создать», ни Enter не срабатывали и ничего не сообщали. Теперь в новой базе (при первом запуске и через «Создать базу») и в очищенной сразу есть папка «Новые ссылки» — та же, куда кладёт ссылки расширение; а если папок всё же нет (например, все удалены), ссылка сохраняется в «Новые ссылки», и папка заводится заново. Существующую базу программа сама не меняет. Пустой адрес больше не игнорируется молча — окно подсказывает «Введите адрес». Заодно ссылка из расширения больше не попадает в папку «Новые ссылки», лежащую в корзине.

2.3.3-beta
  + Большие базы работают быстро. На базе в 91 000 ссылок и 3 800 папок создание папки занимало около 7 секунд — программа перестраивала всё дерево целиком, включая ссылки в свёрнутых папках, и заново читала всю базу. Теперь дерево строится только для раскрытых папок, а создание папки, добавление ссылки (в том числе из расширения), перетаскивание и «Переместить в…» меняют только затронутое место: создание папки — около 0,15 секунды. Открытие базы тоже быстрее: вместо 460 тысяч элементов строится сотня-другая. Окно «Переместить в…» на такой базе открывалось 17 секунд — исправлено; «Свернуть все папки» занимало 10–13 секунд, теперь меньше секунды. «Развернуть все папки» на очень большой базе по-прежнему занимает заметное время — это явная команда, и строить приходится всё.
  + Заметка правится прямо на месте: щелчок по заметке под списком или в карточке превращает её в поле ввода. Сохраняется при уходе из поля и по Ctrl+Enter, Esc отменяет правку. Переход на другую ссылку сохраняет молча. Высоту заметки можно менять, потянув за её верхний край; под списком и в карточке высота своя и запоминается.
  + Дата добавления ссылки. Записывается при каждом добавлении — вручную, из буфера, из расширения, импортом. Показывается в строке состояния и в «Свойствах» ссылки. У ссылок, добавленных прежними версиями, даты нет — там ничего не показывается. Импорт из ua.dat, из другой базы, из HTML и из браузеров (Chrome, Edge и другие браузеры на Chromium, Firefox) сохраняет исходную дату закладки; экспорт в HTML записывает её в файл, и её видит браузер при импорте. Сортировка по дате ставит ссылки без даты в конец.
  + Строка состояния, как в старом URL-Album: внизу окна — «Добавлено» и «Рисунок» выделенной ссылки. Дата рисунка — время снимка страницы; у ссылок из ua.dat — дата из старой программы, пока рисунок не обновят. Раньше дата добавления стояла справа от адреса — теперь там её нет. Текст строки состояния стал крупнее и чётче.
  + Переход набором букв, как в Проводнике Windows: в дереве или в списке наберите начало названия — выделится первый подходящий элемент; пауза в секунду начинает набор заново, повтор одной буквы переходит к следующему элементу на неё. В дереве поиск идёт только по раскрытым папкам. При быстром наборе папка или карточка открывается один раз, после последней буквы. Enter по выделенной в списке папке открывает её, как двойной щелчок.
  + Правая кнопка в любом поле ввода — переименование папки, поиск, заметка, окна «Новая ссылка» и «Свойства», настройки — открывает меню «Отменить / Вырезать / Копировать / Вставить / Удалить / Выделить всё»; недоступные пункты серые. Раньше в поле переименования открывалось меню папки, а в остальных — меню браузера с лишними пунктами и без «Удалить». В поле пароля прокси «Вырезать» и «Копировать» недоступны.
  + Меню «Справка»: сайт программы, репозиторий на GitHub, «Сообщить об ошибке» и окно «О программе» с номером версии. Программа выпускается под лицензией GNU General Public License версии 3 или более поздней; текст лицензии — в файле LICENSE рядом с программой.
  ! «Добавить из буфера» — из трея, по F8 и по своей горячей клавише — больше не спрашивает разрешения на доступ к буферу обмена. Раньше окно программы показывало запрос «хочет просматривать текст и изображения, скопированные в буфер обмена», и адрес в «Новую ссылку» не попадал, пока не ответишь. Пробелы и перевод строки вокруг скопированного адреса теперь отбрасываются. Если буфер в этот момент занят другой программой, окно «Новая ссылка» всё равно открывается, а внизу появляется подсказка вставить адрес вручную.
  ! Расширение браузера в быстром режиме больше не добавляет повторно адрес, который уже есть в базе, если в настройках включено «Запретить повторяющиеся ссылки», — так же, как окно «Новая ссылка». Вместо «Добавлено» расширение сообщает «Уже есть в папке …». Настройка действует сразу, без перезапуска. Старое расширение с новой программой при включённой «Запретить повторяющиеся ссылки» покажет «Добавлено ✓», ничего не добавив, — обновите его: замените файлы в папке, из которой расширение было загружено, файлами из папки extension этого архива (или загрузите его заново из новой папки) и нажмите значок перезагрузки у URL Album в chrome://extensions (edge://extensions).
  ! Переименование папки сразу видно в правой панели и в пути над списком — в том числе из «Свойств папки» и при переименовании папки, в которой лежит открытая. Раньше старое имя оставалось до перехода в другую папку.
  ! «Переместить в…» раскрывает в дереве путь к папке назначения, даже если та лежала в ещё не открывавшейся ветке.
  - Программа больше не пишет в реестр Windows — как и обещано в начале этого файла. Раньше при каждом запуске она регистрировала протокол urlalbum:// (ключ HKCU\Software\Classes\urlalbum), хотя им не пользовалось ни расширение, ни сама программа. Ключ, оставшийся от прошлых версий, можно удалить вручную (regedit, или в командной строке: reg delete HKCU\Software\Classes\urlalbum /f): программа его больше не создаёт и при запуске не использует.
  При первом открытии базы этой версией в ней создаётся служебный индекс для быстрой загрузки дерева — на базе в 91 000 ссылок около 0,2 секунды, файл базы немного растёт. Даты, импортированные из ua.dat прежними версиями, переводятся в общий формат. Прежние версии программы с такой базой работают как раньше.

2.3.2-beta
  ! Размер снимка, заданный в «Настройки → Рисунок», теперь применяется и к закладкам, добавленным через расширение браузера. Раньше в режиме быстрого добавления такие закладки всегда снимались 1280x800, какие бы размеры ни стояли в настройках: расширение добавляет закладку минуя окно программы, и до неё эти настройки не доходили. Остальные способы — ручное добавление, буфер обмена, горячая клавиша — работали правильно, поэтому разница была заметна только при сравнении файлов.
  ! Снимок в правой панели масштабируется целиком, а не обрезается по краям при изменении ширины панели. Как в оригинальном URL-Album.
  ! Расширение браузера само переподключается к программе. Если программа запущена из другой папки — например, обновление распаковано в новое место, — раньше первый щелчок по кнопке расширения давал «ошибка авторизации», а список папок при этом молча исчезал; помогало только повторное открытие окна расширения. Теперь подключение обновляется само, папки перечитываются, и достаточно одного нажатия «Добавить». Заодно исправлено сообщение, когда программа не запущена: раньше окно обещало, что закладка уйдёт в «Новые ссылки».
  ! Импорт из другой базы сохраняет ваш порядок закладок и папок — раньше он выстраивал их в порядке создания, а порядок папок вообще менялся от раза к разу. Переносятся и значки сайтов.
  ! Импортированное больше не вклинивается между существующими записями, а встаёт в конец выбранной папки. Это касается любого импорта, а не только импорта из другой базы.
  ! Импорт из TXT — один пункт меню вместо двух: программа сама определяет по содержимому, свой это экспорт или простой список ссылок. Список ссылок кладётся в пустую папку как есть, а в непустую — в отдельную папку с именем файла, чтобы не перемешаться с тем, что там уже лежит. Если часть файла разобрать не удалось, программа говорит, сколько строк пропущено, вместо того чтобы сообщать об успехе.
  ! Многострочные заметки переживают выгрузку в TXT и обратный импорт. Раньше терялся не только хвост заметки: строка с переносом сбивала разбор, и часть закладок оказывалась не в своих папках. Файлы, выгруженные прежними версиями, читаются по-прежнему — потерянный хвост в них восстановить нельзя, но структура больше не страдает.
  ! В папке Data больше не копятся лишние файлы. Если закладку удалить навсегда, пока идёт съёмка, снимок удаляется вместе с ней; если во время съёмки переключить базу, снимок не приписывается чужой закладке.
  ! Значок сайта больше не пропадает у закладки, восстановленной из корзины, если рядом в корзине лежала другая закладка того же сайта: раньше удаление одной из них уносило общий файл значка.
  ! Правильные окончания в сообщениях: «1 ссылка» вместо «1 ссылок», «2 рисунка» вместо «2 рисунков».
  ! Пункт меню «Файл → Последние базы» теперь действительно открывает базу из списка. Раньше клик по любой записи не делал ничего: команда переключения базы существовала в программе, но не была подключена к её внутреннему механизму вызовов, поэтому список только выглядел рабочим — это не работало никогда, с самого первого выпуска. Теперь при недоступном пути (например, флешка с базой вынута) программа сразу показывает понятную ошибку вместо тишины.
  - Удалён формат «файл синхронизации» (JSON). Синхронизацией он не был: повторный импорт того же файла добавлял всё заново, а заметка с переносом строки давала файл, который программа сама не могла прочитать. Всё, что он умел, умеют импорт из другой базы, HTML и TXT.
  Известное ограничение: снимки, оставшиеся в папке Data от версий до 2.2.4, эта версия не удаляет — до появления корзины удаление закладки файл не убирало, и такие файлы ничем не привязаны. Новых не появляется; команда очистки файлов без владельца появится в следующих версиях.

2.3.1-beta
  + Повторный запуск показывает уже открытое окно вместо второй копии. Раньше щелчок по ярлыку при работающей программе открывал ещё одну, работающую с той же базой. Теперь вторая копия молча завершается, а окно уже запущенной программы выходит на передний план — в том числе когда она свёрнута в трей. Ссылка, открытая через urlalbum://, попадает в уже запущенную программу, а не теряется; заодно исправлены испорченные русские буквы в названии такой ссылки.
  + Работает на чистой Windows без дополнительных установок. Раньше на системе, где не установлен Microsoft Visual C++ Redistributable, программа не запускалась вовсе — Windows показывала окно «Не удаётся продолжить выполнение кода, поскольку не обнаружена VCRUNTIME140.dll». Теперь всё необходимое встроено в сам файл программы, портативность больше ничем не ограничена. Программа выросла на 143 КБ.
  ! «Открывать через…» теперь действует при любом способе открытия ссылки. Раньше настройку учитывали двойной щелчок в дереве и в списке, Enter и пункт «Открыть» в меню «Ссылки», а карточка (кнопка «Открыть в браузере», щелчок по адресу, двойной щелчок по картинке), строка с адресом внизу окна, результат поиска и пункт «Открыть» в меню по правой кнопке — нет: они открывали ссылку системным браузером. Из-за этого два способа открыть одну и ту же ссылку давали разные браузеры.
  ! Список браузеров и панель инструментов больше не теряются, если файл настроек испорчен — например, открыт и сохранён в Блокноте с другой кодировкой или обрезан при сбое. Раньше в таком случае молча применялись значения по умолчанию, и первое же сохранение затирало файл: пропадали вручную добавленные пути к переносным браузерам и расстановка кнопок. Теперь прежний файл сохраняется рядом с программой (browsers.json.bad, toolbar.json.bad), и программа сообщает об этом одним окном, даже если испорчено несколько файлов сразу. В такой копии settings.json.bad код доступа для расширения браузера заменяется звёздочками — файл можно приложить к письму или сообщению на форуме.
  ! Программа больше не молчит, когда ссылка или картинка не открылась. Раньше щелчок по ссылке мог не дать вообще ничего: ни окна браузера, ни сообщения. Теперь программа называет причину — браузер не найден (удалён или лежал на съёмном диске), файл отсутствует, для ссылок такого вида не назначена программа.
  - Убран пункт «Открыть в переносном браузере» из меню «Ссылки»: он никогда не работал и всегда открывал окно «Открыть с помощью». Тот же выбор доступен в подменю «Открыть с помощью» по правой кнопке, где перечислены все браузеры, включая переносные.

Если что-то не работает — включите запись, повторите действие и пришлите файл url-album.log, который появится рядом с программой: по нему проще найти причину. Рядом кнопка «Открыть журнал».
  ! Надёжное сохранение при выходе: раньше последние изменения могли не попасть в файл базы, если скопировать album.db сразу после закрытия программы. Теперь при выходе данные всегда дописываются в базу.
  ! Резервные копии теперь всегда содержат самые свежие изменения — раньше в копию могли не попасть последние правки.
  ! Настройки больше не сбрасываются, если файл settings.json был открыт и сохранён в Блокноте.
  ! Убрано лишнее меню браузера («Назад», «Обновить», «Сохранить как»), всплывавшее при правом клике на пустых местах окна.
  ! Исправлено «Очистить базу»: при ошибке закладки больше не удаляются, а сообщение об отказе теперь соответствует действительности.
