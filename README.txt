URL Album 2.3.3-beta
====================
Портативный менеджер закладок. Не требует установки, не пишет в реестр.
Windows 10/11.

Обозначения:  + новое   ! исправлено   - удалено

ЧТО НОВОГО В 2.3.3-beta
-----------------------
+ Большие базы работают быстро. На базе в 91 000 ссылок и 3 800 папок
  создание папки занимало около 7 секунд, теперь — доли секунды; так же
  быстро добавление ссылки, перетаскивание и «Переместить в…». База
  открывается быстрее, окно «Переместить в…» больше не думает 17 секунд.
+ Заметка правится прямо на месте: щёлкните по ней под списком или в
  карточке. Высоту заметки можно менять, потянув за её верхний край.
+ Дата добавления ссылки. Показывается внизу окна и в «Свойствах».
  При импорте из браузеров и HTML сохраняется исходная дата закладки,
  при экспорте в HTML — записывается в файл.
+ Строка состояния, как в старом URL-Album: внизу окна дата добавления
  выделенной ссылки и дата её рисунка. Текст внизу стал крупнее и чётче.
+ Переход набором букв, как в Проводнике: наберите начало названия в
  дереве или в списке — выделится первый подходящий элемент. Enter по
  выделенной папке в списке открывает её.
+ Правая кнопка в полях ввода открывает меню «Отменить / Вырезать /
  Копировать / Вставить / Удалить / Выделить всё».
+ Меню «Справка» и окно «О программе». Программа выпускается под
  лицензией GNU GPL 3.0 или более поздней — текст в файле LICENSE.
! «Добавить из буфера» (трей, F8) больше не спрашивает разрешения на
  доступ к буферу обмена.
! Расширение браузера не добавляет повторно уже сохранённый адрес, если
  включено «Запретить повторяющиеся ссылки», и сообщает, в какой папке
  он уже есть. Обновите расширение: см. ниже.
! Переименование папки сразу видно в правой панели и в пути сверху.
! «Переместить в…» раскрывает путь к папке назначения.
- Программа больше не пишет в реестр. Раньше при каждом запуске она
  регистрировала ссылки вида urlalbum://. Ключ HKCU\Software\Classes\urlalbum,
  оставшийся от прошлых версий, можно удалить вручную: программа его больше
  не создаёт и при запуске не использует.

Обновление расширения: замените файлы в папке, из которой расширение
было загружено, файлами из папки extension этого архива (или загрузите
расширение заново из новой папки), затем в chrome://extensions
(edge://extensions) нажмите значок перезагрузки у URL Album. Со старым
расширением при включённой «Запретить повторяющиеся ссылки» повторный
адрес покажется как «Добавлено ✓», хотя добавлен не будет.

При первом открытии базы новой версией в ней создаётся служебный индекс
(на базе в 91 000 ссылок — около 0,2 секунды, файл немного растёт).
Прежние версии с такой базой работают как раньше.

ЧТО НОВОГО В 2.3.2-beta
-----------------------
! Размер снимка из настроек теперь применяется и к закладкам, добавленным
  через расширение браузера. Раньше в режиме быстрого добавления они всегда
  снимались 1280x800, какие бы размеры вы ни выставили.
! Снимок в правой панели масштабируется целиком, а не обрезается по краям
  при изменении ширины панели.
! Расширение само переподключается, если программа запущена из другой папки.
  Раньше первый клик давал «ошибка авторизации», а список папок молча
  пропадал; теперь достаточно одного нажатия «Добавить».
! Импорт из другой базы сохраняет ваш порядок закладок и папок и переносит
  значки сайтов. Импортированное встаёт в конец выбранной папки, а не
  вклинивается между существующими записями — это касается любого импорта.
! Импорт из TXT — один пункт меню вместо двух: программа сама определяет,
  свой это экспорт или простой список ссылок, и сообщает, сколько строк
  не разобрала. Многострочные заметки теперь переживают выгрузку в TXT
  и обратный импорт.
! В папке Data больше не копятся лишние файлы: снимок закладки, удалённой
  навсегда во время съёмки, удаляется вместе с ней.
! Значок сайта больше не пропадает у закладки, восстановленной из корзины,
  если рядом в корзине лежала другая закладка того же сайта.
! Пункт меню «Последние базы» теперь открывает базу из списка. Раньше
  клик по любой записи не делал ничего — команда переключения базы не была
  подключена к программе, и это не работало никогда, с самого начала.
- Удалён формат «файл синхронизации» (JSON): он не объединял базы, а вставлял
  записи заново, и на многострочных заметках выдавал файл, который сам же
  не читал. Для переноса есть импорт из другой базы, HTML и TXT.

Известное ограничение: снимки, оставшиеся в папке Data от версий до 2.2.4,
эта версия не удаляет — до появления корзины удаление закладки файл не
убирало. Команда очистки файлов без владельца появится позже.

УСТАНОВКА ПРОГРАММЫ
-------------------
1. Распакуйте архив в любую папку.
2. Запустите URL-Album.exe.

Папку extension НЕ удаляйте — она нужна для браузерного расширения.

Windows может показать окно «Система Windows защитила ваш компьютер».
Это фильтр SmartScreen: программа не подписана платным сертификатом
разработчика, поэтому система её пока не знает. Нажмите «Подробнее»,
затем «Выполнить в любом случае». Исходный код открыт:
https://github.com/mucronix/url-album-tauri

Обычно WebView2 уже есть в Windows 10/11. Если при запуске программа
сообщает «Could not find the WebView2 Runtime» — установите Microsoft
Edge WebView2 Runtime (Evergreen Bootstrapper) с сайта Microsoft:
https://developer.microsoft.com/microsoft-edge/webview2/
Это бесплатно и около 2 МБ.

УСТАНОВКА РАСШИРЕНИЯ (Chrome / Edge)
------------------------------------
1. Откройте страницу расширений:
   - Edge:   edge://extensions
   - Chrome: chrome://extensions
2. Включите "Режим разработчика".
3. Нажмите "Загрузить распакованное" и выберите папку extension
   из этого архива.
4. Иконка URL Album появится на панели браузера (её нужно будет закрепить).

ВАЖНО: программа URL Album должна быть запущена — расширение
связывается с ней. Если программа закрыта, расширение покажет
"URL Album не запущен".

ОБНОВЛЕНИЕ ПРОГРАММЫ
--------------------
1. Закройте программу.
2. Распакуйте новый архив в ту же папку, поверх старых файлов.
3. Запустите URL-Album.exe.

Ваши данные при этом не пострадают: архив содержит только программу,
README и папку extension. База закладок, скриншоты в папке Data
и настройки лежат отдельно и не перезаписываются.

Расширение браузера обновляется само вместе с папкой extension:
переустанавливать его не нужно. Если хотите применить обновление сразу,
откройте страницу расширений браузера и нажмите "Обновить" в верхней
части страницы.

Важно: не переносите и не переименовывайте папку с программой после
установки расширения - браузер запоминает путь к папке extension
и после переноса потеряет расширение. Если папку всё же пришлось
переместить, установите расширение заново из нового расположения.

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Запустите URL Album.
2. Откройте нужную страницу в браузере.
3. Нажмите иконку расширения.
4. Выберите папку, в которую сохранить ссылку (по умолчанию "Новые ссылки").
5. Нажмите "Добавить в URL Album".
6. Ссылка со скриншотом появится в выбранной папке.

Даты, импортированные из ua.dat прежними версиями, переводятся в общий формат. Прежние версии программы с такой базой работают как раньше.

  ! Размер снимка, заданный в «Настройки → Рисунок», теперь применяется и к закладкам, добавленным через расширение браузера. Раньше в режиме быстрого добавления такие закладки всегда снимались 1280x800, какие бы размеры ни стояли в настройках: расширение добавляет закладку минуя окно программы, и до неё эти настройки не доходили. Остальные способы — ручное добавление, буфер обмена, горячая клавиша — работали правильно, поэтому разница была заметна только при сравнении файлов.
  ! Снимок в правой панели масштабируется целиком, а не обрезается по краям при изменении ширины панели. Как в оригинальном URL-Album.
  ! Расширение браузера само переподключается к программе. Если программа запущена из другой папки — например, обновление распаковано в новое место, — раньше первый щелчок по кнопке расширения давал «ошибка авторизации», а список папок при этом молча исчезал; помогало только повторное открытие окна расширения. Теперь подключение обновляется само, папки перечитываются, и достаточно одного нажатия «Добавить». Заодно исправлено сообщение, когда программа не запущена: раньше окно обещало, что закладка уйдёт в «Новые ссылки».
  ! Импорт из другой базы сохраняет ваш порядок закладок и папок — раньше он выстраивал их в порядке создания, а порядок папок вообще менялся от раза к разу. Переносятся и значки сайтов.
  ! Импортированное больше не вклинивается между существующими записями, а встаёт в конец выбранной папки. Это касается любого импорта, а не только импорта из другой базы.
  ! Импорт из TXT — один пункт меню вместо двух: программа сама определяет по содержимому, свой это экспорт или простой список ссылок. Список ссылок кладётся в пустую папку как есть, а в непустую — в отдельную папку с именем файла, чтобы не перемешаться с тем, что там уже лежит. Если часть файла разобрать не удалось, программа говорит, сколько строк пропущено, вместо того чтобы сообщать об успехе.
  ! Многострочные заметки переживают выгрузку в TXT и обратный импорт. Раньше терялся не только хвост заметки: строка с переносом сбивала разбор, и часть закладок оказывалась не в своих папках. Файлы, выгруженные прежними версиями, читаются по-прежнему — потерянный хвост в них восстановить нельзя, но структура больше не страдает.
  ! В папке Data больше не копятся лишние файлы. Если закладку удалить навсегда, пока идёт съёмка, снимок удаляется вместе с ней; если во время съёмки переключить базу, снимок не приписывается чужой закладке.
  ! Значок сайта больше не пропадает у закладки, восстановленной из корзины, если рядом в корзине лежала другая закладка того же сайта: раньше удаление одной из них уносило общий файл значка.
  ! Правильные окончания в сообщениях: «1 ссылка» вместо «1 ссылок», «2 рисунка» вместо «2 рисунков».
  ! Пункт меню «Файл → Последние базы» теперь действительно открывает базу из списка. Раньше клик по любой записи не делал ничего: команда переключения базы существовала в программе, но не была подключена к её внутреннему механизму вызовов, поэтому список только выглядел рабочим — это не работало никогда, с самого первого выпуска. Теперь при недоступном пути (например, флешка с базой вынута) программа сразу показывает понятную ошибку вместо тишины.
  - Удалён формат «файл синхронизации» (JSON). Синхронизацией он не был: повторный импорт того же файла добавлял всё заново, а заметка с переносом строки давала файл, который программа сама не могла прочитать. Всё, что он умел, умеют импорт из другой базы, HTML и TXT.
  Известное ограничение: снимки, оставшиеся в папке Data от версий до 2.2.4, эта версия не удаляет — до появления корзины удаление закладки файл не убирало, и такие файлы ничем не привязаны. Новых не появляется; команда очистки файлов без владельца появится в следующих версиях.

Раньше в таком случае молча применялись значения по умолчанию, и первое же сохранение затирало файл: пропадали вручную добавленные пути к переносным браузерам и расстановка кнопок.
